Camera Stream (Real-time video input):

The webcam or camera is continuously streaming video frames.

Object Detection (YOLOv8):

Use YOLOv8 to detect and crop objects in real-time frames.

Image Embedding (Feature Extraction):

Convert both stored images and real-time detected objects into vector embeddings (e.g., using a CNN like CLIP, ResNet, or MobileNet).

Matching via Vector Search (Pinecone + FAISS):

Output Result (Live Feedback):

Display match result in real-time (e.g., ✅ Found: Watch.jpeg, or ❌ Not found).
